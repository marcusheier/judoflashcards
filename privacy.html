Privacy

Last updated: 13 October 2026

Cookieless analytics

Judo Flash Cards uses Google Analytics to understand general site use. It runs in a privacy-restricted Consent Mode with analytics and advertising storage denied, so it is configured not to read or write analytics or advertising cookies. Google may still receive limited cookieless measurement data, including page activity and basic technical information. Advertising personalization and Google advertising signals are disabled.

For more information about how Google handles data, see Google’s Privacy Policy.

Information you submit

Judo Flash Cards does not provide user accounts, contact forms, or payment forms, so you cannot submit personal information directly through this website.

Hosting

This static website is hosted by GitHub Pages. As the hosting provider, GitHub may process technical connection information such as IP addresses and request logs according to GitHub’s own privacy practices.

External links

The Ko-fi support link opens an external website only after you choose to click it. Ko-fi’s own privacy and cookie practices apply once you leave Judo Flash Cards.

Future changes

If data-processing features or analytics cookies are added later, this notice will be updated and any legally required choices will be presented before those features are activated.
